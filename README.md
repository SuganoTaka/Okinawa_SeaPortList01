# Okinawa Fishing Map

## Render Blueprint

This app is stored in the `Okinawa_FishingMap` subdirectory of the GitHub repository.
When creating the Render Blueprint, set the Blueprint file path to
`Okinawa_FishingMap/render.yaml` (do not select `README.md`).

The Blueprint installs the Node.js package and starts the web service with `npm start`.
It serves the prebuilt app from `dist/` and the JMA tide endpoint from the Node.js server.
